# 1MS25IS040-Assignment2

## ReAct Agent Implementation Using Gemini API

This project demonstrates the implementation of a **ReAct (Reasoning and Acting) Agent** using Google's Gemini API and a document search tool.

### Features
- Uses Google's Gemini model to process user questions.
- Implements a search tool to retrieve relevant information from a predefined document collection.
- Uses a ReAct loop to decide when to search for information and when to generate a final response.
- Supports follow-up questions and general knowledge questions.

### Technologies Used
- Python
- Google Gemini API
- Google Colab
- Google GenAI SDK

### How to Run
1. Open the notebook in Google Colab.
2. Configure your Gemini API key using Colab Secrets.
3. Run the notebook cells in order.
4. Test the agent using the provided questions.

### Project Structure
- `Agent_Demo_Loop.ipynb` – Main notebook containing the ReAct agent implementation.
